# Heart-Disease-Prediction-R
Heart Disease Prediction using R with Data Analysis, Visualization and Logistic Regression.
# ❤️ Heart Disease Prediction using R

## Project Overview
This project analyzes heart disease data using R programming. It includes data cleaning, exploratory data analysis (EDA), visualization, and Logistic Regression to predict heart disease.

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Logistic Regression
- Confusion Matrix
- ROC Curve
- Accuracy Calculation

## Technologies Used
- R:R is the primary programming language used in this project. It is used for data loading, data cleaning, statistical analysis, visualization, and building the Logistic Regression model for heart disease prediction.
- RStudio:RStudio is the Integrated Development Environment (IDE) used to write, execute, debug, and manage the R code. It provides tools for viewing datasets, plots, console output, and project files in one place.
- ggplot2:ggplot2 is used to create high-quality data visualizations. In this project, it generates histograms, bar charts, scatter plots, and box plots that help analyze the distribution of patient characteristics and identify trends.
- dplyr:dplyr is used for efficient data manipulation and transformation. Although the dataset required minimal cleaning, this package provides functions to filter, select, arrange, summarize, and modify data.
- corrplot:corrplot is used to visualize the correlation matrix. It helps identify positive and negative relationships between variables such as age, cholesterol, blood pressure, and heart disease.
- pROC:pROC is used to evaluate the performance of the Logistic Regression model. It generates the ROC curve and calculates the Area Under the Curve (AUC), which measures the model's ability to distinguish between patients with and without heart disease.
